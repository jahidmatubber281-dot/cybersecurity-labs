# Cybersecurity Lab Reports

This repository contains hands-on cybersecurity lab reports, network analysis, security testing, and practical exercises using the following tools:

- **Nmap** — Network scanning and service discovery
- **Snort IDS** — Intrusion Detection System for monitoring suspicious network traffic
- **Wireshark** — Network packet capture and protocol analysis
- **SQLmap** — Automated SQL injection testing in authorized labs
- **Nikto** — Web server security scanning
- **Dig** — DNS lookup and troubleshooting
- **WHOIS** — Domain registration and ownership information lookup
- **Ollama** — Running local large language models for AI-assisted learning and experimentation
- **John the Ripper** — Password security auditing
- **Kali Linux** — Linux-based cybersecurity testing environment

**Purpose:** To document practical cybersecurity learning, lab experiments, findings, and security analysis.

**Disclaimer:** All testing is conducted in authorized lab environments or on systems for which permission has been granted.
